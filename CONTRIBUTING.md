# Contributing

Thank you for your interest. **Outside contributions are not accepted during
the beta.** Pull requests from outside the project will be closed without
review, so please do not spend time on one yet.

When contributions open, they will need a contributor licence agreement (CLA),
which will be introduced at that point and linked from here. Until then there
is nothing to sign.

## Security

Report vulnerabilities privately to **security@hasala.app**. Please do not open
a public issue, pull request or discussion for a security problem. Include what
you found, how to reproduce it, and what it affects.
